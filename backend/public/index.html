SECURITY ARCHITECTURE

Built so a screenshot is worthless.

Hashed passwords + 2FA

Passwords are Argon2id-hashed with breach list protection. Every sign-in requires a 6-digit TOTP authenticator code.

30-second signed tokens

QR codes are signed by the IdP and expire in 30 seconds. They hold only a pseudonymous reference, not raw personal data.

Replay protection

Each code works once. A re-used code is blocked, raises an immediate alert, and revokes all active sessions.

Minimal disclosure

Services see only the fields an admin and student have permitted — nothing more. Pairwise IDs prevent cross-tracking.

Smart alerts

Flags impossible travel (rapid multi-city logins), brute-force attempts, and unauthorized account recovery.

Full transparency

Append-only SHA-256 hash-chained audit logs. Students see their access trail; admins verify cryptographic integrity.
